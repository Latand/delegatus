Цифри під рядком лейну

Окремим рядком під PR лейну — ≈3% ≈2%, витрата саме цього лейну. Рядок лейну зі стадіями, часом і PR лишається таким, як без цифр. Підказка ділить витрату за етапами. Задача з кількома лейнами показує кожен окремо. На готовій картці числа стоять наприкінці рядка стану. Поки лейн не дав першого числа, рядка з цифрами немає; без даних про ліміт стоїть слово «невідомо».
