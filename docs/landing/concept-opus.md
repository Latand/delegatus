# Delegatus landing: concept (Opus)

Status: research, one of two independent concepts. A later lane merges this
one with the GPT-6 Pro concept (`gpt-pro-brief.md` asks for it) into a
prototype. Nothing here changes product code.

## The requirement

The operator dictated it on 2026-09-26 to the project's orchestrator seat, in
Russian. Paraphrased in English, per the repository's publication rules and the
operator's standing request that dictated statements are paraphrased:

> Delegatus needs a landing page. First research, then a prototype. One
> concept should come from GPT-6 Pro and a separate one from Opus, and a later
> Opus lane integrates both. Look at a domain too, probably bought through
> Cloudflare.
>
> The page introduces Delegatus as an orchestrator: you hand it work and it
> knows how to do it well and efficiently, with checks, fully autonomously,
> and with reports. Full traceability: you can open any conversation and
> search across all of them. Multiple accounts. Agents talk to each other,
> across Claude Code and Codex. A native Telegram MCP.
>
> Minimal, good-looking, anti-slop; use every design skill available and
> find references. Minimum text, maximum pictures, three or four sections
> at most. Install preferably through the visitor's own agent (Claude Code or
> Codex), with a box to copy the prompt. Separately a "legacy" install through
> Bun for people who still use a terminal, where the Delegatus mascot giggles
> at them for it ("ha-ha, you use a terminal").

Every decision below is checked against that paragraph in the last section.

## 1. Positioning

**One line.** Delegatus is the agent you hand your software work to: it runs
Claude Code and Codex agents with fresh reviewers, checks what they did,
reports as each piece lands, and keeps every conversation open to read.

**Headline** (kept from the README, so the brand says one thing everywhere):

- EN: **Delegate everything.**
- UK: **Делегуй усе.**

**Sub-line under it** (one sentence, the only paragraph in the hero):

- EN: Tell one agent what you want shipped. It runs the builders and
  reviewers, checks the work and reports back.
- UK: Скажи одному агенту, що треба зробити. Він запускає розробників і
  рев'юерів, перевіряє роботу і звітує.

Why this angle: the neighbours sell a nicer place to run agents by hand
(Conductor's headline is "Run a team of coding agents", Vibe Kanban's is
about the human's planning and review). Delegatus is the only one in that
set where an agent runs the other agents, so the page leads with the handoff
and shows the machinery second.

## 2. Page structure

Four sections and a footer. Visible copy outside the install prompt stays
under 120 words per language; each section carries one heading and at most
three one-line captions. Pictures are real Delegatus screens from the seeded
demo project `harbor-api`, which is what the README captures already use
(`docs/media/readme/*.svg`, generated by `scripts/capture-readme-media.ts`
from `scripts/readme-demo-state.ts`, all synthetic data).

Navigation bar: the mark (20 px) and "Delegatus" on the left; on the right
GitHub (with the star count), Docs (the README), and an EN / UK switch. No
other links, no sign-in, no pricing.

### Section 1: the handoff (hero)

**Layout, desktop (≥1024 px).** Two columns on a slate ground. Left, 5/12:
headline, sub-line, the install box. Right, 7/12: the hero screen, bleeding
off the right edge of the viewport. The mascot stands on the left edge of the
screen frame, about 96 px tall, half over the frame and half over the ground.

**Layout, phone (<640 px).** Headline, sub-line, then the phone board capture
(`phone-board.svg`) at full width with the mascot perched on its top edge,
then the install box. The install box is still above the second fold.

**What the hero screen shows.** The orchestrator capture
(`orchestrator.svg`): the seat's chat with the operator on the left, the
**Reports** log on the right, the board beneath. It is the one screen that
holds the whole promise: you say one line, it answers, reports stack up.

**The signature motion: "the handoff".** The only authored animation on the
page, about 9 s, runs once when the hero enters the viewport and then holds
its last frame (a small replay control sits in the frame's corner):

1. 0–2 s: the composer types the operator's line: "Take the open harbor-api
   work: idempotent refunds first, then the webhook retries and the key
   rotation." (the line already in the capture).
2. 2–3 s: send. The message bubble folds into a small paper note and slides
   to the mascot, which catches it, nods once, and its glasses glint.
3. 3–6 s: the orchestrator's answer streams in; on the board below, the
   Build → Review → Verify chips of "Idempotent refunds" light up one after
   another, the green "working" dots appear on two cards.
4. 6–9 s: three entries drop into the Reports log from the top, newest first
   ("Build passed…", "in Review…", "stopped on a decision…"), and the amber
   **Needs you 1** pill in the header pulses once.

`prefers-reduced-motion`: the final frame, static, no fold, no pulse.

Build it from layers cut out of the real capture (composer, answer, board
chips, report entries as separate crops over a base frame), animated with CSS
and the Web Animations API. No video file, so it stays sharp at every DPR and
is re-generated whenever the README captures are.

**Install box** (full copy in §3). A two-tab box, "Claude Code" | "Codex",
showing the first three lines of the prompt and a **Copy prompt** button;
the full prompt is what lands on the clipboard. Under it, one quiet text
link: "I still use a terminal" (UK: «Я ще користуюсь терміналом»), which
opens the legacy box in place (§4).

## 3. The install box

Two tabs. Each copies a complete prompt the visitor pastes into their own
agent. The prompt names every command, so a careful visitor can read what
the agent is about to run. Paths and commands are the ones the README
documents today (Bun 1.4+, `bun add -g delegatus-cli`, port 8898, MCP key
`viewer`); `claude mcp add` and `codex mcp add` were checked against the
installed CLIs' `--help` on 2026-09-26.

**Claude Code** (EN; the UK page copies the same prompt with a Ukrainian
last line, "Відповідай українською"):

```text
Install Delegatus on this machine and connect yourself to it.
Project: https://github.com/Latand/delegatus

1. Run `bun --version`. If Bun is missing or older than 1.4, install it with
   `curl -fsSL https://bun.com/install | bash`, then use ~/.bun/bin/bun if
   `bun` is not on PATH yet.
2. Install the CLI: `bun add -g delegatus-cli`
3. Start it in the background so it keeps running after this session:
   `mkdir -p ~/.cache/delegatus && nohup ~/.bun/bin/delegatus --no-open > ~/.cache/delegatus/server.log 2>&1 &`
   Wait up to 60 seconds for http://127.0.0.1:8898/ to answer. If it does
   not, show me the last 30 lines of that log.
4. Register its MCP server for yourself:
   `claude mcp add viewer -s user -- delegatus-mcp`
   (it becomes available in your next session).
5. Give me the link to open. The setup guide there connects my agents,
   picks a project and creates its orchestrator.

On native Windows, stop after step 1 and tell me to run this inside WSL 2.
```

**Codex**: the same prompt with step 4 replaced by:

```text
4. Register its MCP server for yourself:
   `codex mcp add viewer -- delegatus-mcp`
   (it becomes available in your next session).
```

The visible part of the box shows the first three lines of the prompt in
Martian Mono, fading out at the bottom edge, with **Copy prompt** on the
right. After a copy, the button reads "Copied. Paste it into Claude Code" (or
Codex) for 2 s.

## 4. The legacy install and the joke

"I still use a terminal" expands a small dark box in place:

```text
bunx delegatus-cli
```

with one line under it: "Needs Bun 1.4+: `curl -fsSL https://bun.com/install | bash`".

**The joke.** As the box opens, the mascot pops up from behind its top-right
corner (only the head and glasses clear the edge), looks at the command,
and giggles: shoulders shake in two short cycles (2 × 180 ms), the glasses
bounce 2 px, and a speech bubble appears:

- EN: "Hehe. Typing commands yourself? How vintage."
- UK: «Хі-хі. Сам набираєш команди? Як вінтажно.»

The bubble stays until the visitor copies the command; after the copy it
changes to "Fine. I'll be in the browser." (UK: «Гаразд. Я чекатиму в
браузері.») and the mascot ducks back down. With reduced motion, the mascot
appears already up, bubble shown, no shake.

The label says "legacy" only in the box's own small title ("Legacy install",
«Застаріле встановлення»). The teasing stays affectionate, one line, and
never blocks the command: a terminal user copies it in one click like anyone
else.

## 5. The mascot

The emblem already exists (`public/brand/`, described in
`docs/design/delegatus-brand.md`): a round red bird (`#E0392B`) with a cream
belly, swept grey hair and bold glasses, no beak. On the page it is
Delegatus itself, the one you hand the note to.

Three poses, drawn in the same flat SVG construction as
`delegatus-mark.svg` (same palette, same 3.6 px glasses stroke at 64 px):

1. **Catching** (hero): wings out, the folded note arriving.
2. **Giggling** (legacy box): eyes squeezed into arcs, one wing over the
   mouth area, shoulders up.
3. **Perched** (phone section and the phone hero): sitting on the top edge of
   a frame, legs hanging over, glasses turned toward the content.

The mascot never appears more than once per viewport, never wears costumes,
and is never a loading spinner. It is the only warm, saturated object on the
page, so wherever it sits, the eye goes there.

## 6. Visual direction

**Ground and colour.** Dark by default, because the screens are dark
captures and the visitor is a developer at a desk; the page matches the
product's own dark tokens (`src/styles/tokens.css`):

| role | value | source |
| --- | --- | --- |
| page ground | `#111218` | `--surface-canvas`, dark |
| raised surfaces (install box) | `#191b23` | `--surface-card`, dark |
| hairlines | `#292c36` | `--border-default`, dark |
| primary text | `#fbebdd` | `--color-brand`, dark (the cream) |
| footer band ground | `#fbebdd`, ink `#262a36` | the brand pair |
| mascot red | `#E0392B` | the emblem only, never a UI colour |
| live signals (dots in captions) | the product's own working green, needs-you amber | the state tokens |

Red lives only in the bird. Cream is text on slate and one band at the end,
which keeps the page out of the cream-paper-plus-red look that
AI-generated landings default to (the calibration list in the impeccable
design skill names it).

**Type.** Three faces, all SIL Open Font License on Google Fonts, all with
Cyrillic, checked in the Google Fonts metadata on 2026-09-26:

- **Unbounded** (NaN), weight 700, for the headline and the four section
  headings only. Its wide, round letterforms rhyme with the round bird.
  Headline `clamp(2.75rem, 6vw, 5.5rem)`, tracking −0.02em, balanced wrap.
- **Geologica** (Monokrom), variable, for everything else: captions 18 px /
  1.5, weight 400; the sub-line 22 px; the sharpness axis at 0.
- **Martian Mono** (Evil Martians), only inside the install and legacy
  boxes, where the text is literal and gets pasted.

Self-host the three as subsetted WOFF2 (Latin + Cyrillic), with
metric-matched fallbacks so nothing reflows on load.

**Screens.** No fake window chrome, no traffic lights, no tilt. Each capture
sits in a frame with a 1 px `#292c36` border and a 14 px radius, bleeding off
the viewport edge on desktop so the product looks larger than the page. The
README captures are full-DOM SVG exports of 0.3–3.3 MB; for the web, add a
landing case to `scripts/capture-readme-media.ts` that writes AVIF and WebP at
1× and 2× plus the layer crops the hero animation needs, and records them in
`docs/media/readme/provenance.json` (the privacy publication gate refuses
committed rasters without generator provenance). One driver, extended; no
new capture script.

**Motion.** One authored moment (the handoff), one secondary (the pass edge
drawing once), one character beat (the giggle). Easing
`cubic-bezier(0.16, 1, 0.3, 1)`, 400–700 ms, from an already-visible
state, so nothing flashes in from blank. No scroll-jacking, no parallax, no
per-section fade-ins.

**Browser surfaces.** Text selection in cream on `#3c404c`, the focus ring
in the product's violet accent, the scrollbar thumb `#3c404c`, tabular
numerals for the version and the star count.

**Hosting.** A static page, separate from the app: plain HTML, CSS and a few
hundred lines of JavaScript for the tabs, the copy and the two animations;
deployed on Cloudflare Pages under the domain from `domain-options.md`. The
Viewer's Next.js build is the wrong home for it: the page needs none of the
app, and a landing change should never ride a Viewer release.

Anti-references, looked at for what to avoid:

- [Vibe Kanban](https://vibekanban.com/): cream grid paper, a terracotta
  accent, tracked monospace labels and a numbered "1. PLAN, 2. PROMPT,
  3. REVIEW" row. That is the generated-landing cluster, on the closest
  kanban neighbour (which on 2026-09-26 showed a banner announcing it is
  sunsetting).
- [Warp](https://www.warp.dev/): monospace for every word, as a costume
  for "technical". Mono on this page is reserved for text you paste.

## 8. What to avoid

- An eyebrow or kicker above any heading, section numbers, gradient text.
- A row of same-size cards (icon, heading, two lines) as a section.
- A logo wall of Anthropic, OpenAI or GitHub marks; name the tools in text.
- Stats and hero metrics ("10× faster", counters). The screens are the proof.
- Stock "AI" imagery: sparkles, glowing orbs, neural nets, robots.
- Fake window chrome and tilted screenshots.
- More than one animation running at a time; scroll-triggered fade-ins on
  every block.
- Emoji or Unicode glyphs as icons; icons, if any, come from the product's
  own lucide set.
- Invented claims. Every sentence on the page must be true of `1.5.0`: no
  "cloud", no "teams", no pricing, no testimonials.
- A mascot that talks outside the legacy box, or that talks down to the agent
  path. The joke is on terminal habits, once.

## Deferred: not currently justified

- **A video or GIF hero.** The layered animation is sharper, lighter and
  regenerates with the captures. The promo GIF tracked separately can reuse
  the same layers later.
- **A light theme toggle.** The screens are dark captures; a light page would
  need a second capture set.
- **Docs site, blog, changelog pages.** The README is the documentation for
  now; the nav links to it.
- **Team features, pricing, a hosted offer.** The operator is exploring a team
  edition separately; the page must not promise it before it exists.
- **Analytics beyond Cloudflare's own aggregate counts.** Nothing asked for it.
- **Mascot name and a character sheet beyond three poses.**
- **A Copilot tab in the install box.** Copilot agents run in Delegatus, but
  orchestrators and pipelines run on Claude Code or Codex, so the two tabs
  match what the operator asked for and what the orchestrator needs.
