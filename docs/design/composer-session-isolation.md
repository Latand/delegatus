# Typing while other conversations are active

The 2026-11-24 request for issue #4285 asks that a person typing into a conversation on a busy board see keystrokes appear as promptly as in a plain field on that board. The editor must still respond to their conversation, loss or recovery of the connection, and the fate of their send. The implementation needs a visual critic to measure the changed field before and after. The requirement comes from the 2026-11-20 architecture review, §6, lines 61–69, and issue #4285.

## How a foreign event reaches the screen

1. An SSE message enters `handleEnvelope`. A heartbeat updates the last-event time. An accepted envelope installs the reduced store, a duplicate confirms health, and a revision gap requests a snapshot. The reducer knows the conversation it writes. In particular, a receipt has an operation ID **and** a conversation ID. An attention resolution can recover its owner from the stored attention. The bus batches general notifications on a 16 ms timer and calls every general listener. Files revisions also have a dedicated notification. (`src/hooks/runtimeBus.ts:58`, `src/hooks/runtimeBus.ts:166-181`, `src/hooks/runtimeBus.ts:354-365`, `src/hooks/runtimeBus.ts:385-405`, `src/components/runtime/runtimeModel.ts:538-562`, `src/components/runtime/runtimeModel.ts:577-599`, `src/components/runtime/runtimeModel.ts:759-794`.)
2. The Viewer calls `useFiles(project, pin)`. The project drives a presence heartbeat. The catalog URL asks for a global summary with an optional pin. The hook owns a runtime status projection and its general bus callback checks that projection on each notification. For a new sessions object, even a text-only change can enumerate both key sets to prove board status equal. A lifecycle change can filter all sessions, serialize a signature, rebuild lookup maps, clear the row cache, walk the catalog for terminal generations and map its files. The final equality check can then return the *same* files array and wrapper. (`src/components/Viewer.tsx:291`, `src/hooks/useFiles.ts:131-137`, `src/hooks/useFiles.ts:1745-1779`, `src/hooks/useFiles.ts:1958-1975`, `src/lib/client/runtimeFilesStatus.ts:19-27`, `src/lib/client/runtimeFilesStatus.ts:53-83`, `src/lib/client/runtimeFilesStatus.ts:104-135`, `src/lib/client/runtimeFilesStatus.ts:150-165`, `src/lib/client/runtimeFilesStatus.ts:184-199`, `src/lib/client/runtimeFilesStatus.ts:243-254`.)

## Decision

**Route accepted changes to the readers that own them.** Keep the existing transport, reducer, draft owner and files cache. Add keyed notification to the tab's runtime bus and attach the board status overlay to the current catalog. Look up the identities changed by an accepted event. If conversation B has no row or aggregate on the screen and supplies none of conversation A’s controls, its update must cause zero row evaluations there and zero notifications to A’s editor.
