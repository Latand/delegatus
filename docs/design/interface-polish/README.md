# Interface polish patches

Prototype patches for issue #2148, described and ranked in
[`../interface-polish.md`](../interface-polish.md). None of them is applied
to the product. Each applies on its own from the repository root, and all
eight apply together in any order:

```
git apply docs/design/interface-polish/01-status-pill-neutral-in-columns.patch
```

The file numbers are the order the patches were written. The design document
ranks them by visible gain per line of code.
