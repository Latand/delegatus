Delegate everything.

One agent runs your board. Claude Code and Codex build and review. You see every agent and can step in.

Free and open source. Runs the official CLIs on your machine, with your own logins.

Delegatus runs on your computer. The prompt below is for an agent there.

  1. 1New projectA new project: an empty board and no orchestrator yet.
  2. 2OrchestratorOne click creates its orchestrator, the agent that runs the board.
  3. 3RequestYou tell it what you want, in your own words.
  4. 4TasksIt turns the request into tasks on the board.
  5. 5PipelineThe orchestrator starts the work: Claude Code builds, a fresh Codex reviewer checks.
  6. 6DoneMerging on a passed review is on here, so the PR merges and the card moves to Done.

Demo, invented data

It runs the work, and checks it.

  • Each task gets a worktree, a builder and a fresh read-only reviewer.
  • Claude Code builds, Codex reviews, and they message each other.
  • A failed review sends the work back to the builder, within a round budget.
  • Decisions come to you, and you can pause any pipeline. Merging on a passed review is off by default.

Every conversation, open.

It finds you when it needs you.

  • Your board on your phone, inside your tailnet.
  • A decision waits on its card, with the finding and the two ways forward.
  • Telegram built in: agents read chats you allow and report through your bot.

Questions people ask first.

Does it get around Anthropic’s or OpenAI’s terms?

No. Delegatus starts the official Claude Code and Codex CLIs, signed in with your own accounts, the way you would start them in a terminal. It does not share or resell access. Your provider’s terms and limits apply as always.

Is it Claude Code with a new face?

Claude Code and Codex do the work inside it. Delegatus adds what sits around them: an orchestrator that keeps a board of tasks, a worktree for each task, a fresh read-only reviewer for every round, decisions that wait for you on their card, and every conversation open and searchable.

What leaves my machine?

The board and every conversation stay on your machine, and the agents talk to their providers as they always do. Delegatus itself sends one anonymous install ping a day: a random id, the version, OS, architecture and install kind. Turn it off in Settings or with DELEGATUS_TELEMETRY=0.

Does it merge pull requests by itself?

Only when you turn that on. Merging on a passed review is off by default: a pipeline ends with its pull request open, and the orchestrator tells you it is ready.

Do I need both Claude Code and Codex?

No. Either one runs the orchestrator and the builders. With both, one engine builds and the other reviews. GitHub Copilot can run single agents too.

What does it cost?

Delegatus is free and open source under the MIT license. The agents run on your own Claude, Codex and Copilot accounts, within the plans you already have.

Free and open source. Runs on your machine with your own Claude Code or Codex.
